# TUI Decisions 12-14 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The TUI names its session after the host, keeps the mode line out of the status bar, and lets the user select session rows to see their details.

**Architecture:** All three changes are in `internal/tui`, with the hint computed in `internal/cli/tui.go` and passed in through `tui.Options`, so `internal/tui` stays free of host lookups.

**Tech Stack:** Go, Bubble Tea v2, Lip Gloss v2.

**Spec:** `docs/superpowers/specs/2026-10-21-gate-0-decisions.md`, section "TUI decisions (Eric, 2026-10-22)", items 12-14; `docs/tui.md`.

## Global Constraints

- `internal/tui` imports only `internal/bus` and `internal/version` of this module (`scripts/m8-exit-checks.sh --deps-only`).
- `scripts/m8-exit-checks.sh` counts `TestBothModes` (2), `TestNoInboxView` (1) and `TestRunTUI{Local,Server}Profile` (2): keep those names and leaf counts.
- Docs updated with the code: `docs/tui.md` (line 27 naming, line 49 and 51 sessions section, the status bar description, line 195 "No session selection"), `CLAUDE.md` `tui` bullet if it mentions the name.
- Per task: `make lint`, `make test`, `bash scripts/m8-exit-checks.sh --deps-only`.

## Review Focus

1. A hostname such as `MacMini.local`, `host_name`, an empty string or one over 128 bytes: the hint is valid or falls back to `tui`, never an Open error.
2. The swept-session resume (`client.go` `resumeLapsed`) reopens with the same hint as the first open, not `tui`.
3. Selecting a session row never calls `History`, `Subscribe` or any per-session bus operation (`TestNoInboxView` still proves no inbox view).
4. The session list changes under the selection (a session goes idle, a new one appears): the selection stays valid or moves to the heading, never out of range.
5. A narrow terminal: the status bar stays one row (existing truncation) with the shorter content.
